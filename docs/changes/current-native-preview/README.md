# 当前原生界面效果（2026-11-05）

本目录截图来自真实 Tauri / WebView2 应用，使用回退工作台布局后的前端构建资源。为避免单实例转发到已安装旧版，截图构建仅通过临时配置把实例标识改为 dev.ziedit.visual-review，未改生产代码或配置。使用独立示例文本与独立配置；随后已关闭截图实例，并重新构建常规标识的桌面可执行文件。

截图视口为1280×832 CSS像素，系统设备像素比1.25，完整原图1600×1040；局部图通过原生截图裁取视口区域，无DOM替换、样式注入或伪造工作台。

## 原布局核对

- 生产 TOOLBAR_SPEC 与仓库 HEAD 一致，原工具栏CSS段与 HEAD 一致。
- 原工具栏动作：新建、打开、保存、另存为；撤销/重做；剪切/复制/粘贴；查找/替换/跳行；原视图上下文组；右侧命令面板与主题。
- 实际工具栏 overflow-x 为 visible，右侧位置为 static；额外横滚和sticky右区均已移除。
- 工具栏、标签栏、状态栏实际高度为32/28/28 CSS像素。

## 当前保留的界面修改

| 范围 | 当前修改 |
|---|---|
| 菜单标题 | 保留文件(F)等括号助记字母；展开与键盘焦点状态 |
| 菜单内容 | 统一勾选、名称、快捷键、箭头列及分隔线；禁用项状态 |
| 右键/长菜单 | 真实尺寸定位、限高滚动、子菜单翻转与键盘进退、关闭后焦点返回 |
| 设置 | 七组设置、分组说明、标签关联、颜色开关与重置联动、正文滚动与固定保存取消；保存语义保持 |
| 快捷键 | 搜索、分类、分组计数、按键键帽、两列对齐、内部滚动、初始搜索焦点 |
| 使用说明 | 中英各12章、目录导航、独立正文滚动、完整仓库指南 |
| 键盘/语义 | 工具栏具名与按下状态；标签方向键切换/Delete关闭；状态格Enter/Space；弹窗焦点隔离与返回 |
| 仍保留的小样式 | 活动文件树左侧强调线、活动标签顶部强调线、状态格细边框（不改变几何） |
