# 体验整改：滚动位置 / 即时渲染 / 功能联动（任务卡）

状态：阶段 0—4 及阶段 5 的公共机制抽取已实施，分支 ux-scroll-anchor；本轮待最终复核后提交。

## 依据（2026-10-30 全仓只读审计）

用户主诉：即时渲染毛病多且卡、滚动条跑到最上或最左、缩略图显示不好、Markdown 小毛病修一个冒一个、功能有的能用有的不能用、整体不丝滑。审计结论是五个结构性原因，而非孤立 bug：

1. 滚动位置按像素记录并跨形态搬运（`app.ts` 旧 1411/1426、`livepreview.ts` 旧 274、`edit.ts` 旧 704）；源码/即时渲染/预览行高各不相同。CM6 自带的 `scrollSnapshot()` 未使用。
2. 即时渲染有多处各自补偿滚动位置：`live-block-field.ts` 停稳补偿（`restoreSettledAnchor`）、`table-viewport.ts` 行高纠偏，外加 CM6 自身锚定；另有 8 套以上缓存/窗口/帧预算机制互相牵制。
3. Markdown 三条渲染路径（即时渲染 CM6 装饰、预览 Lezer→HTML、预览 markdown-it 回退），样式各写一份（`styles.css` 预览段与 `.md-ir` 段）。
4. `app.ts` 约 6400 行几乎全在 `boot()` 闭包内，无「当前视图能做什么」的统一接口；各命令自行 `instanceof` 判断，渲染预览时 currentView 是隐藏源缓冲、分屏时是左侧编辑器，判断频繁出错。
5. 切标签/切形态整视图销毁重建（清空 viewarea 后异步挂载），是「僵硬」的主要来源。
6. 横向：1100+ 单测全在 jsdom（无布局），滚动与错位类问题测不出。

## 阶段 2：即时渲染停稳不弹（2026-10-30）

真机门 `tests/gates/gate-ir-settle.mjs` 先测基线：停手后 1.5s 内视口顶部内容最大位移 38px、中线 94px，scrollTop 每 ~340ms 一轮 ±25~180px 往复，12 轮 10 轮失败。查得三处叠加：

1. CM6 滚动锚因块高度变化改写 scrollTop 也派发 scroll，`viewportReporter` 把它当用户滚动 → 进滚动占位 → 换占位改变高度 → 锚点再补偿 → 再派发 scroll，自持振荡。
2. 停稳补偿 `restoreSettledAnchor` 另写一次像素补偿，与 CM6 自带锚定（更新前记锚块、测量后按高度差改 scrollTop）叠加。
3. 公式滚动中换占位（源行数×21.6）、停稳换回加载态（`<code>` 源码约 40px）、出图（实际高度），一次换件高度变两次；表格行高初值 32px 沿用旧紧凑样式，实测 47~49px。

改法：

- `common/user-scroll.ts`：只有输入事件（滚轮/触摸/导航键/指针按下）或显式登记（缩略图拖动、自绘滚动条）才算用户滚动；`liveBlockField` 与 `liveDeco` 只在用户滚动时走滚动占位/分片，程序跳转与锚点补偿直接完整渲染。
- 删停稳像素补偿与滚动流判定，视觉位置只由 CM6 锚定负责；`TableViewport` 的表内锚点纠偏保留（视口顶落在超长表格内部时 CM6 锚块是整张表，表内行高变化它看不到）。
- 公式/图表滚动中不再换占位，直接上实件；已渲染过的同步出图（`cachedRender`），加载态按估计/实测高度预留（`--md-render-reserve`），实测高度按内容身份记忆供估计复用；用户滚动中推迟 MathJax/Mermaid 排版到停手（滚动中不出长帧）。
- 表格行高初值改为共享常量 `TABLE_ROW_ESTIMATE_PX = 48`（layout.ts，对齐当前表格 CSS）。

实测（mixed-100k.md / dense-2m.md，WebView2）：

|---|---|---|
| gate-ir-settle 顶部 / 中线最大位移 | 38.1 / 93.6px，10/12 失败 | 1.5 / 2.0px，12/12 通过 |
| gate-ir-scroll（dense-2m）全文档 vs 去表格基线 | — | p95 16.8 = 16.8ms，>34ms 帧 0 = 0，PASS |

`gate-batch1-scroll` / `gate-ir-scroll` 原先因 Markdown 默认形态改为渲染预览而测的是隐藏源缓冲或进不了 IR 面，已补「先经菜单切到即时渲染」；`gate-batch1-scroll` 的阶梯写 scrollTop 模拟拖动滚动条，每步先派发 wheel 登记用户意图。

## 阶段 4 前半：切标签保留视图（2026-10-30）

修前每次切标签都销毁当前视图、清空视图区，再异步重建（读缓冲、建编辑器、重算装饰、重挂公式），切回时先空白再出内容。

- 源码编辑面与即时渲染面改为每视图一个独立宿主（`.view-host`），跨标签切走时隐藏宿主暂存（缩略图移出共享右轨、状态快照随行），切回原样显示并按快照还原位置；对比视图与日志尾随台也改用独立宿主（二者销毁时清空宿主，修前清的是整个视图区）。
- 只跨标签暂存；同一文件换形态照旧重挂并作废旧形态暂存（两个活视图持同一文档会分叉）。最多暂存 4 个，超 2M 字符的文档不暂存。
- 切回前逐项核对：缓冲文档仍是暂存时那份、脏标未被后台保存改变、无待应用的崩溃恢复、影响视图构造的设置（字号/只读/软换行/行号/选中高亮/不可见字符/缩略图/语言/编码覆盖）未变；任一不符即销毁暂存、按缓冲重挂（旧路径）。
- 暂存中的视图不写当前视图的全局状态（只记标签脏标）；查找栏的 document 级 Esc 监听在宿主隐藏时不吞键。

实测：`gate-scroll-position` 新增 F——即时渲染标签切走再切回，DOM 为同一份（未重建）、点击后 65~73ms 可见、视口顶行不变（1018.07→1018.07），8/8 通过；`gate-ir-settle` 12/12 通过。

`gate-ir-scroll` 说明：本会话后段显示刷新约 54Hz，单个掉帧即 37ms，超过该门 34ms 判线。同机同刷新率下阶段 1 构建（402b5a4）两轮为 5/6 个 vs 基线 2/1（FAIL），当前构建三轮为 6/8/6 vs 1/3/5（FAIL/FAIL/PASS），两者同一水平，非本轮回退；60Hz 时当前构建为 0 vs 0（PASS）。

## 阶段 3 第一步：元素级一致（2026-10-30）

新增真机门 `tests/gates/gate-md-consistency.mjs`：一份含全部常用元素（六级标题、段落行内格式、引用、有序/无序/嵌套/任务列表、代码块、表格、分隔线、脚注）的样例文档，同一窗口先后进渲染预览与即时渲染，逐元素比对计算样式（字号/字重/字形/行高/颜色/底色/装饰线/字体族）与几何（正文起点、表格/分隔线宽度），亮暗主题各一轮。

实测：阶段 0 补的行内样式之后，元素级只剩表格两处差异——即时渲染表格按内容收缩（宽 170px），预览撑满阅读栏（812px，6f7eaf6 的定稿只落在预览侧）；预览未指定对齐的表头落浏览器默认居中，即时渲染靠左。均已修正，门亮暗两轮通过。另合并重复的即时渲染脚注规则。

已登记的实现差异（门内 ALLOWED，观感等价）：引用/代码块的行高声明位置不同；任务列表复选框盒宽不同，正文差约 3px。

**块间距（用户定稿：即时渲染向预览看齐）。** 空行 `.mdir-gap` 改为 `min-height:0;line-height:0;padding-top:var(--mdir-gap-height)`，块间距仍只在连续空行首行分配一次，光标激活类不改盒尺寸，空行仍可进入编辑。`gate-md-consistency` 新增主要块纵向坐标断言（代码块的逐行盒/单一 pre 盒差异登记 ALLOWED），亮暗两轮通过。

## 阶段 3 收尾、4 后半、5（2026-10-30）

- Markdown 主路径 Lezer→HTML 与异常回退 markdown-it 共用 `.md-col` / `.md-preview,.md-ir` 样式令牌；保留异常回退以保证资产失败时可读可用，不为消除引擎名称而移除可靠性通道。亮暗深色表头沿用既定设计，未擅改。
- 缩略图条纹减淡/圆角、视口框 accent-soft；滚动条轨道翻页 160ms ease-out，尊重 `prefers-reduced-motion`，滚轮、地图和滑块拖动即时响应；新增 `--ui-fs-*`、`--ui-space-*`、`--ui-radius-*`、`--ui-motion-*`。
- `shell/view-capabilities.ts` 统一能力矩阵，书签/跳转/可编辑面启用改走同一判决；`shell/view-lifecycle.ts` 管独立宿主与 LRU，`shell/mount-epoch.ts` 管代次/路径锁，`markdown-view/preview-anchor.ts` 管预览位置补校正；工具栏/菜单由 `refreshViewCommands()` 统一刷新。

实测：`tsc` 通过；153 个测试文件、1141 项单测通过；`gate-md-consistency` 亮暗 PASS；`gate-scroll-position` 8/8 PASS；`gate-ir-settle` 12/12 PASS，顶部/中线最大位移 0.3/0.4px。

## 决策

- 跨形态只保证「视口顶源码行」一致；块级件（表格/公式）在即时渲染下整体一块，锚落块首（真机门容差 6 行）。
- 同形态（切标签回来）用 CM6 快照，像素与横向位置精确还原；文档已变（重载/切编码）时缓冲本就丢弃，不复用快照。
- 当时缩略图按行坐标、滑块按像素坐标。此决策已被 [Markdown 统一改造](markdown-unification.md) 覆盖：渲染地图、视口框与滑块共同读取排版快照；下表保留历史实测。
- 亮色主题下的深色表头是提交 6f7eaf6 刚恢复的既定取舍，本轮不动；是否改为随主题，待用户决定。
