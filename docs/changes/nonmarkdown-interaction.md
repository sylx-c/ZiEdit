# 非 Markdown 交互整改与走查

2026-11-02。用户反馈：TXT 无法自由选字或选行、列模式难用、中文界面托盘右键仍为英文。上次只完成工程检查，没有完成要求的全功能实际走查；既有测试通过不能替代这次验收。

## 已复现与修复

- 纸白主题及自定义当前行色为不透明底色，盖住绘制在 z=-2 的 CM 字符选区；选区内部正确但看起来只有整行灰底。当前行底色改在 z=-3 的伪元素绘制，文字与选区层保持清晰。
- 列模式或 Alt 手势同一行拖选，在 mouseup 时被清空成光标；改为保留普通字符选区，反向拖选同样可用。
- 编辑器快捷键开启列模式后，工具栏未同步选中态；按状态变化同步刷新。
- 列键盘选区只用排序后的矩形边界扩展，向上扩展与反向缩回失效；保存固定起点与活动端点。
- Escape 和文档修改时清理旧的键盘固定端点，重新扩选使用当前光标或更新后的矩形边界。
- 列拖选用逻辑行首的 x 推列坐标，软换行后列偏移错误；改用 CodeMirror 命中字符位置，行尾之外再追加虚拟列。
- 列拖选越界滚动只续算一次；改为持续按帧滚动，鼠标移动取消旧帧，结束与销毁解绑。
- 行号区明确支持单击选择整条逻辑行、Shift 扩展行范围；正文单击只定位光标。
- 托盘原先只在手动切换语言时更新；启动设置加载完成后也同步最终界面语言，覆盖未保存语言而系统/缓存为中文的情况。
- 走查补获命令面板 Enter 漏入正文：排序等动作同步聚焦编辑器后确认键额外插入换行；执行前阻止默认输入及冒泡。
