## 1.0.2 - 2026-11-18

- 弹窗体系统一（设置整改方向 B）：① 弹窗尺度固化为三档并在样式源头注明——S 常规小框（默认样式，保持不变）/ M 中型（设置：560px、20px 边距、15px 标题）/ L 大型（帮助与指南：700–820px、24px、17px），M/L 档关闭按钮统一为 28px；② 帮助中心与设置共用同一复合搜索框组件（放大镜图标 + 清除按钮 + 聚焦描边发光，图标改为单一样式来源）；③ 焦点样式统一口径——文字类控件（输入框/下拉）为「强调色边框 + 光晕」，按钮类为强调色 outline 焦点环，并补齐全局对话框按钮此前缺失的 focus-visible 样式。
- 设置弹窗瘦身：高度不再顶满窗口（上限 min(600px, 视口−120px)），宽度 640→560px（1276×831 视口下弹窗从约 640×782 降为 560×487 以内）；左侧全高分类列改为顶部横向页签（当前分类高亮显示），默认一次只看一个分组、任意分组无需滚动即可看全；搜索时自动切换为跨分组扁平结果，无匹配时新增空态提示；删除顶部说明行与各分组内复述组名的提示行；设置行控件统一右缘锚线对齐、行距收紧；底部按钮区去掉分隔线与双重间距。设置项与保存/取消行为不变。
- 修复（发布验收真机门禁发现）：阅读面锚定两处间歇失效（约 1/8 概率被逐帧采样锁定，插桩定位）。① 懒加载图片落位跳动一帧——Chromium 对图片是「固有尺寸先进布局绘制、load 事件后到」，锚定补偿因此晚一帧；无尺寸线索的图片现于加载期经 `.md-asset-reserve` 收为 0 高，真实高度只在 load/error 任务内释放，落位位移与锚定补偿同帧完成。② 字号/布局变化偶发整差无补偿——原生滚动锚定的部分校正先于自家补偿触发 scroll 事件，重记基线把未补偿位移当成用户新位置、反吞视觉锚补偿；现重记前判别「无新输入且视觉锚文档位置变化」的滚动为布局交付回声，保留旧视觉锚待补偿到位（纯滚动与新输入后的滚动照常重记）。
- 修复（发布验收真机门禁发现）：点击标签后其悬停提示（title）会永久变空——提示层在「指针悬停」时即摘下原生 title 以抑制 WebView2 原生提示，但标签栏每次渲染全量重建元素，点击后指针停在原位时浏览器对新元素补发悬停事件，新元素的 title 被摘下后再无「离开/按下」事件恢复。现摘下时机移到自定义提示层实际显示时（260ms 后）：快速点击（含点击标签）全程不摘，提示层可见期间行为不变、离开仍恢复（真机 position 门禁两轮确定性失败锁定，回归测试 5 例）。
- 修复（真机演示复验发现）：对比标签的伪路径在标题栏与状态栏被原样铺开——窗口标题显示成整条 URL 编码的 `compare%3A%2F%2F…`，看不出哪两个文件在比；状态栏提示区同样。现在两处都与标签栏同源，显示「A ↔ B」（如 `①预算表-旧版.xlsx ↔ ①预算表-新版.xlsx`）；显示名收口到 `src/common/tab-title.ts` 一处实现（草稿/尾随台/对比伪标签统一）。
- 关于对话框：构建 SHA 保持纯文本溯源标识；版本号与渠道标记点击即跳转对应链接，三者均不再显示悬停文字提示（无障碍标签保留，读屏可用）。

- 修复（代码审查发现）：① 视图菜单里手选的「文本 / 富预览」此前重启后失效——锁定状态只在本次运行有效（会话保存时该字段被丢弃），现在随会话持久化，重开同一文件仍保持你选择的形态。② 双表对照的联动滚动改按「用户正在操作的那一侧」驱动：短表滚到底后不再把长表拉回（长表尾部可正常滚到），也不会偶发吞掉一次滚动。
- 修复（代码审查发现）：对比标签悬停提示与对比视图文件名里的同类问题——悬停提示此前打印整条 `compare://` 编码串（现为「A ↔ B」+ 两侧完整路径，草稿/尾随台给显示名）；对比头部文件名误用等宽字体，带圈数字等字符（如 `①`）被符号字回退成小字号，现文件名沿用界面字体并优先完整显示（空间不足时先撤次要的投影说明、摘要文字收缩，动作按钮不再被裁掉）。
- 修复（真机演示复验发现）：Excel/Word 文件对比在插入行、删除行处显示「详情加载失败：OOXML_WINDOW…」——对齐块一侧没有行时坐标为 0，Office 投影窗口把它当非法窗口报错（纯文本对比不受影响）。现在 0 基/倒序窗口按空侧处理、投影总行数照常回报，变更块详情正常显示（新增回归测试锁定）。
- 修复（性能复验发现）：Word 文本提取的 10MiB 上限存在行头双重记账——段落很多的文档（如 12 万段、实际 8.9MiB）会被误判超限无法打开；已修正并加回归测试。
- 修复（真机门禁复验发现）：① Word 富预览此前无法取得文档字节——zasset 资产协议的类型表未含 docx 家族，文件请求被 403 拒绝，富预览实际从未渲染（一直回退文本）；现补齐 docx/docm/dotx/dotm 类型。② 重新打开已打开的文件时，标签保留旧路由不随新探测刷新——富预览一旦回退过一次（或会话残留旧路由），该文件此后永远以文本投影打开，「默认富预览」失效；现激活已有标签时按本次打开的探测路由刷新。真机复验：Office 冒烟门禁 7/7 通过（显示值、公式开关、sheet 页签、富预览分页渲染）。

- Word 文档默认以**富预览**打开（批 5）：按文档原样式分页渲染（docx-preview，仅预览模式按需加载）；视图菜单可切换「富预览 / 纯文本」；渲染失败或文档超过 100MiB / 20 秒守护上限时自动回退文本投影并说明原因。富预览为只读形态，需精读搜索时可切纯文本。涉及新依赖 docx-preview（Apache-2.0）及传递依赖 jszip（双许可明示选 MIT）/pako/isarray，许可证据与门禁全部通过（未决 0）。
- 查看与对比扩面（批 4）：pptx 演示文稿可看可对比——按幻灯片提取文本（每页一行标题 + 段落行，幻灯片按数字序排列），对比投影与差异导航照常可用。`.wps`/`.et`/`.dps`：内容为 OOXML/ODF 包（PK 头）的走对应管线正常打开对比；WPS 私有二进制容器（OLE）显式提示「请用 WPS 打开后另存为 docx/xlsx/pptx」，对比入口对旧式 Office/WPS 二进制（.doc/.ppt/.wps/.et/.dps）同样给出另存为指引（替换一刀切文案）。`.doc`/`.ppt` 支持完成 spike 初评：候选 docboss 在 crates.io 不存在（排除）；rwml（MIT）通过许可/架构两关、正确率与内存两关待实测——按决策不预先引入，两周实测期后定论（见 `docs/changes/office-compare-batch4-doc-ppt-spike.md`）。

- Excel/Word 家族扩面与显示值口径（批 2）：内核换为 calamine + ooxml-numfmt（均宽松许可，许可证据齐备），Excel 列按 Excel 显示值参与查看与对比——日期列不再显示序列数（如 45292 → 2024-01-01），百分比/布尔/错误按格式渲染，1904 历法正确换算；sheet 页签旁新增「公式」开关（显示值 ↔ =公式），对比头部新增「公式口径」开关（值同公式不同可检出）。新增可打开格式：.xls/.xlsb/.xlsm/.xltx/.xltm/.xlam/.ods（Excel 家族）与 .docm/.dotx/.dotm/.odt（Word 家族，odt 读正文段落）；.xls 从文件树二进制隐藏名单移出。.ods 采用自有有界解析（上游 calamine 对截断内容会挂起，实测复现并规避，见 `docs/changes/office-compare-batch2.md`）。上限哨兵全部沿用（包 100MiB/行 20 万/列 1024/提取文本 10MiB）。
- 对比：混合对（Word/Excel 对纯文本）不再误报「BOM」徽标——投影侧无字节层，BOM 与编码/行尾一样不适用；Excel 投影按 (路径, 大小, 修改时间) 缓存，对比视图滚动取行不再重复投影（20 万行级对比打开与同规模文本对比同量级，实测数据见 `docs/changes/office-compare-batch1.md`）。
- 对比：Word（.docx）与 Excel（.xlsx）文件对比从不可用变为可用的文本投影对比。此前 docx/xlsx 按原始压缩字节逐行对比，改动一个字或仅重新保存都会整篇标红；现改为提取正文/工作簿值后按内容行对比——同内容重新保存为 0 差异，改一处只报一处，差异导航、概览条与行内六类高亮照常可用。Excel 按「工作表标题 + 逐行取值」投影并保留稀疏行对齐；混合对比（docx 对 txt）同样支持。对比头部对投影侧改示「Word 文本投影 / Excel 值投影」（悬停显示提取范围），不再显示无意义的编码/BOM/行尾；任一侧 Word 文档含修订标记时显示「含修订」徽标，按接受全部修订后的终态口径对比。`.doc`/`.xls` 等旧格式与图片等二进制内容的拒绝行为不变。

- 文件树：未知扩展名（如 `.lkn`）的文件若内容为二进制，默认不再出现在树里——此前只有已知二进制扩展名（exe/dll/压缩包/音视频等）免嗅探隐藏，未知扩展名一律当文本显示，打开却是乱码。现改为目录展开时对未知扩展名按批内容嗅探（首 4KB，进程内缓存；已知扩展名仍免嗅探，不增加目录扫描开销），嗅探为二进制的与已知二进制同口径隐藏；设置「文件树显示全部文件格式」开启时仍全量展示。嗅探失败（权限等）按保持显示回退。同因修复：周期性稀疏 NUL 二进制此前会被「无 BOM UTF-16」启发式误认成文本（控制字符检查被短路、打开乱码），现解码码元控制字符占比超 10% 即拒绝该猜测。
- 界面桌面化三则：① 工具栏、状态栏、菜单栏、最近列表等未提供自定义右键菜单的面不再漏出 WebView2 浏览器默认菜单（输入框/文本域保留系统复制/粘贴菜单）；② 最近打开列表支持右键清理（移除该记录/清空全部，与收藏行同口径）；③ 图标悬停提示改为统一自定义层（原生 title 提示在 WebView2 下延迟长且常不重复触发），260ms 稳定出现、离开或按下即隐。
- 状态栏模式格两态强标记：可编辑形态=蓝色实心圆点，只读形态（渲染预览/标签锁）=琥珀色锁形图标——形状与颜色双通道区分，此前只读形态恒灰被读作"颜色没了"；工具栏「编辑|只读」段对称点亮（编辑=蓝、只读=琥珀）。文件菜单「最近打开 ▸」尾部新增「清空最近记录」（菜单项不支持右键，侧栏最近面板的行右键仍可逐条移除/清空）。关于对话框：版本号点击打开下载安装包页（GitHub Releases），「正式版/开发版」渠道标记点击打开 GitHub 仓库首页，构建 SHA 悬停解释其含义。

## 1.0.1 - 2026-11-14

- 本地图片：打开 Markdown 时，指向文档所在共享以外的 UNC 图片不再授权、不再读取。盘符绝对路径仍可用于草稿贴图和显式本地图。zasset 只提供图片、PDF 和字体，单文件读取上限 256MB。
- 路径：创建、改名、保存、删除、字体读取、图片写入、在资源管理器中显示，以及文本、Office、对比的打开路径，都拒绝 Windows 设备路径。保存的编码结果超过 32MB 会拒绝。用系统程序打开时补上符号链接目标和 `.py`、`.sh`、`.scf`、`.settingcontent-ms` 等扩展名。
- 对比：单行超过 1MB 时停止行级哈希并走原有窗口降级，避免无换行文件整段进入内存。跨文件搜索跳过目录联接。S3 取图要求与公网基址的协议一致。
- 会话与命名会话在 Unix 上以私有文件权限落盘。Windows 上用与崩溃恢复相同的 DPAPI 加密；没有加密标记的旧 JSON 仍可读取。解密失败时保留原文件，启动和退出都不会用空会话覆盖它。
- 关于对话框增加官网与 GitHub 入口，点击交给系统浏览器。GitHub 使用官方标记，放在「官网」前面。
- CI 的前端类型检查和 Vitest 加入 macOS，与工作流标题一致。依赖锁里的 npm 解析地址改为 `registry.npmjs.org`。
