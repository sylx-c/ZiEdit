# ZiEdit 蓝墨工作台 · V2

[打开新版 Demo](index.html) · [当前整改方案](../../changes/desktop-refinement-plan.md) · [上一版存档](../desktop-refinement/index.html)

根据“不要太普通，也不要和现在长得太不一样，喜欢现有格局”的反馈重做。这一版保留现有六菜单、分组工具栏、双层侧栏、目录树、连续卡片标签、标尺、缩略图和分段状态栏；重新设计视觉细节，而非简化信息架构。

## 打开方式

直接用桌面浏览器打开 `index.html`，无需安装依赖。样式和脚本为同目录本地文件；等宽字体引用项目已有的 `public/fonts/`。无CDN、在线字体、统计或后端依赖。

本地预览（当前会话）：`http://127.0.0.1:4178/docs/design/desktop-refinement-v2/index.html`。

## 设计重点

- 略暖的纸白画布、冷灰外壳、深墨文字、钴蓝选中与焦点。
- 保留文件蓝、编辑紫、查找青、视图琥珀四组图标，统一双色细线结构。
- 当前文件定位线、标签短蓝标、Markdown章节线、缩略图视口使用同一品牌母题。
- Markdown正文14px，阅读列总宽820px；标题27px、二级18px，不使用展示页式巨字。
- 状态栏保留分段格，去掉Win32凹凸边；标尺和缩略图保留。
- 四主题与舒适/紧凑密度；保持现有主题命名方向。

## 可以体验

- 文件树展开、文件筛选、文件/大纲切换、大纲定位。
- 文件标签切换、方向键导航、关闭标签与从树重新打开。
- Markdown阅读/源码、格式插入、标题级别、编辑/只读锁。
- TypeScript源码编辑与轻量语法着色示意；CSV只读单元格选择定位。
- 查找首项、标尺/缩略图开关、点击缩略图定位。
- 四主题、两档密度、命令面板过滤/方向键/回车执行、下载当前文本。

快捷键：Ctrl/Cmd+K或Ctrl/Cmd+Shift+P打开命令面板；Ctrl/Cmd+F查找；Ctrl/Cmd+S下载文本；Ctrl/Cmd+B/I在Markdown源码中插入加粗/斜体。原型快捷键不构成生产快捷键调整决定。

## 原型边界

编辑仅修改当前页面内存，刷新恢复示例；下载不会回写原始文件。系统窗控为装饰；Markdown为有限安全转义渲染器，TypeScript为轻量着色示意，CSV不使用真实RFC4180引擎。文件系统、IME、虚拟化、PDF/Office/对比不在原型实现范围。

低于960px的额外窄屏探查会隐藏部分格式按钮，仅为避免原型溢出；生产实施必须提供溢出菜单与命令入口，不能照此删除功能。现有Markdown四模式、字体、标尺、缩略图、打开方式与用户配置不因Demo改变。

## 验证记录

使用Chromium / Playwright检查：

- 六个菜单、三级目录树、文件筛选、文件/大纲切换、大纲平滑定位。
- Markdown格式按钮、源码编辑与阅读同步、任意输入转义；TypeScript编辑与着色层同步、未保存反馈。
- 编辑/只读锁、重复点击当前锁不误切换；CSV单元格B2定位。
- 四主题、舒适/紧凑密度、标尺开关、缩略图点击定位、查找首项、命令过滤执行、文本下载。
- 标签方向键、主题radio方向键、Esc关闭及焦点返回。
- 1440×900、1280×832、960×600、760×700、390×844均无页面或工具栏横向溢出。960px保持完整工具栏；更小尺寸为额外原型探查，不是移动版产品承诺。
- 最终预览无浏览器运行时错误。

人工检查了纸白、石墨和960px截图。以上是浏览器原型验证，不代替Tauri原生窗控、操作系统缩放、屏幕阅读器、真实文件引擎或大文件性能验收。

本目录为用户未认可的蓝墨 V2 历史原型。后续已恢复原布局及四主题基础配色；此处 Demo/截图不代表当前源码。当前记录见 [美术与许可审计](../../changes/ui-art-license-audit.md)。


蓝墨 V2 的 P0 已应用到实际前端样式与弹层：四主题、功能色、工具栏反馈、侧栏、标签、标尺/右轨、状态栏、主题卡与命令面板。生产 Markdown 字号、深表头、四模式和用户偏好未改。
