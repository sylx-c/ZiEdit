ZiEdit · 工作台设计预览

这一版探索更安静、更清晰的桌面工作台。可以切换文件、编辑源码、查找、使用命令面板，以及切换四种主题、两档密度和专注模式。

文档是内置示例；编辑内容仅保留在当前页面内存中。保存操作会下载当前文本。文件系统、窗口控制、CSV 数据编辑和原生菜单需要接入 ZiEdit 后端。

快捷键：Ctrl/Cmd+K 打开命令面板；Ctrl/Cmd+F 查找；Ctrl/Cmd+S 下载文本；Ctrl/Cmd+Shift+Enter 专注。
