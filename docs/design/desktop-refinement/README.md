# ZiEdit 桌面工作台 · 交互设计预览

[打开 Demo](index.html) · [整改方案](../../changes/desktop-refinement-plan.md)

这是用于评审视觉方向的独立 HTML 原型。无需安装依赖，直接用桌面浏览器打开 `index.html` 即可；全部样式、脚本、图标和示例文本均在 HTML 内，无 CDN、远程字体或网络依赖。与生产 `src/` 分离。

## 本版可以体验

- 三个内置文件：Markdown 设计笔记、TypeScript 工作台示例、CSV 阅读清单。
- Markdown 阅读 / 源码切换；源码可编辑，修改后阅读区同步；TypeScript 是普通文本编辑示意，无语法高亮或补全。
- 四种主题：纸白、雾蓝、石墨、曜黑；两档密度：舒适、紧凑。
- 文件 / 大纲侧栏、文档定位、可折叠目录、文件标签左右方向键导航。
- 专注模式、查找首项定位、CSV 单元格选择定位。
- 命令面板支持过滤、上下方向键、回车执行、Esc 关闭。
- 下载当前文本；文件、编辑、视图、帮助菜单只列出本原型已实现的命令。

## 快捷键

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 命令面板 | Ctrl+K / Ctrl+Shift+P | Cmd+K / Cmd+Shift+P |
| 查找 | Ctrl+F | Cmd+F |
| 下载文本 | Ctrl+S | Cmd+S |
| 专注模式 | Ctrl+Shift+Enter | Cmd+Shift+Enter |
| 关闭弹层 | Esc | Esc |

上述快捷键是原型演示，不构成修改生产快捷键的决定。部分组合可能被浏览器或系统占用，可使用界面入口。

## 原型边界

编辑内容只保留在当前页面内存中，刷新后恢复内置示例。CSV 为只读预览，下载操作导出文本；不写入真实文件。顶部窗口符号只用于表达桌面布局，没有模拟系统窗口操作。Markdown 使用有限的示例渲染器，任意输入会先转义；生产版继续沿用现有 Markdown 与 CodeMirror 引擎。

Demo 的阅读限宽、主题色、舒适密度、收敛后的菜单和按需辅助区都属于待评审设计提案。生产中的完整菜单、Markdown 三态、字体偏好、标尺/缩略图偏好及已有默认值，不能直接被此原型取代。图片、PDF、Office、双文件对比和大文件性能须按整改方案单独验收。

## 本次验证记录

使用 Chromium / Playwright 检查：

- 1440×900、1280×832、960×600、760×700、390×844：页面和工具栏没有横向溢出。后三者含生产最小桌面窗口与额外窄屏探查；窄屏不代表产品转向移动端。
- 主题切换、密度切换、专注模式、TypeScript 编辑反馈、Markdown 源码到阅读同步与脚本转义、CSV 单元格定位、命令过滤执行、查找首项定位通过。
- 文件标签方向键切换、命令面板方向键、Esc 关闭和焦点返回通过。
- 人工检查纸白、石墨、960px 窄窗口截图。

以上是浏览器原型的检查结果，不代表完成 Tauri、操作系统缩放、屏幕阅读器或真实文件引擎的回归测试。
