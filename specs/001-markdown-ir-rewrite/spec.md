# Feature Specification: Markdown 即时渲染重构（REQ-014）

**Feature Branch**: `feat/markdown-ir-rewrite`

**Created**: 2026-11-19

**Status**: Draft

**Input**: User description: "REQ-014 Markdown 即时渲染重构：以单一统一的渲染投影机制取代两套并行的增量渲染引擎，消除打字不跟手、光标/滚动跳动、三面渲染不一致三类已验证症状；标记显隐与操作行为对齐 Typora 基线；分七阶段实施，每阶段独立可撤回。"

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 连续键入跟手（Priority: P1）

写作者在所见即所得（即时渲染）模式下连续输入中文正文——汉字、空格、中英标点混合——要求每一次按键即时反映，视口不重算、内容不跳动。

**Why this priority**: 打字是写作面的最高频动作；当前空格与标点会触发整视口重建，含图片/公式的正文键入长期不跟手，是本重构的第一动因。

**Independent Test**: 在普通正文（无图片无公式）连续键入汉字/空格/句号，探针 typingRebuildMs 各类 P95 ≤ 8ms；密集语料（含表格文档）键入事务 P95 ≤ 40ms、max ≤ 50ms、无 >100ms 长任务且键序正确。

**Acceptance Scenarios**:

1. **Given** 打开普通中文正文并进入即时渲染模式，**When** 分别连续键入汉字、空格、中英标点各 200 次，**Then** 键入全程跟手，探针 typingRebuildMs（汉字/空格/句号）P95 ≤ 8ms，不触发整视口重算。
2. **Given** 打开约 2MB 密集语料（含表格、公式、图片），**When** 持续键入 5 分钟，**Then** 键入事务 P95 ≤ 40ms、max ≤ 50ms、零 >100ms 长任务，输入序号全部有序。

---

### User Story 2 - 标记显隐稳定、行宽不跳（Priority: P2）

写作者把光标移入标题、加粗、斜体、删除线、行内代码、链接时，源码标记就地显示便于修改；移出后标记隐藏、恢复渲染外观。全程正文行的宽度与起始位置不因光标移动而变化。

**Why this priority**: 行宽跳动是当前被诟病的核心体验问题；标记显隐规则是本重构的行为基线主体。

**Independent Test**: 光标在标题、加粗、链接之间往返移动，探针 cursorWidthChange = 0；块级标记（`#` `>` `-`）显隐切换不改变正文行起始位置（由左侧留白栏承载，不把标记文本插入正文行）。

**Acceptance Scenarios**:

1. **Given** 文档含 1–6 级标题、加粗、斜体、删除线、行内代码、链接，**When** 光标逐个进入这些块再离开，**Then** 标记按「进入显示、离开隐藏」切换，cursorWidthChange = 0。
2. **Given** 光标位于标题行行首/行尾贴边或相邻行（未进入标题正文、选区不相交），**Then** 标题标记保持隐藏，不闪现。
3. **Given** 非空选区与某语法节点相交，**Then** 该节点按「进入该块」处理（标记显示）。

---

### User Story 3 - 滚动与停稳不位移（Priority: P3）

写作者滚动长文经过已渲染的表格、公式、图片时，已挂载的块不被替换重挂；大纲跳转、查找跳转、粘贴大段内容后停稳，视口顶部内容不位移。

**Why this priority**: 「纯滚动替换已挂载块」与「停稳位移」是高度可感知的稳定性问题，且现行验收仅允许 ±2/4px 残差。

**Independent Test**: 纯滚动经过已挂载表格/公式/图片持续 10 秒，探针 scrollReplaceCount = 0；跳转/粘贴后停稳，顶部位移 ≤ 1px（严于现行 ±2/4px 门禁）。

**Acceptance Scenarios**:

1. **Given** 长文含多个已渲染表格、公式、图片，**When** 纯滚动持续 10 秒，**Then** scrollReplaceCount = 0。
2. **Given** 任意文档位置，**When** 大纲跳转、查找跳转、粘贴大段内容后停稳，**Then** 顶部位移 ≤ 1px。

---

### User Story 4 - 三面渲染一致（Priority: P4）

写作者在即时渲染、分屏预览、独立预览三个面查看同一文档，层级、强调、链接、表格、代码、公式、图片的输出完全一致。

**Why this priority**: 三面不一致损害信任（同一文档不同面貌）；统一渲染政策是架构性目标。

**Independent Test**: 五份基准语料（①带粗体和行内代码的 GFM 表格；②真 ATX 标题 1–6 级；③围栏内的假标题；④下划线行 `===`/`---` 应为段落+水平分隔线而非 Setext 标题；⑤嵌套列表+引用+行内公式组合）分别在三面查看，输出一致（截图对比不归一化）。已知差异单独登记，不写白名单。

**Acceptance Scenarios**:

1. **Given** 五份基准语料，**When** 分别在即时渲染/分屏/独立预览三面查看，**Then** 三面输出一致。
2. **Given** 围栏代码块内出现 `# 标题` 形态文本，**Then** 三面均不解析为标题。
3. **Given** 正文行后跟 `---` 下划线行，**Then** 三面均渲染为段落 + 水平分隔线（该口径已于近期修复定稿，本重构不得回退）。

---

### User Story 5 - 表格直接编辑（Priority: P5）

写作者在表格单元格内点击即编辑；Tab/Shift-Tab 在单元格间移动，末列末行 Tab 新建行；撤销一次恢复单格内容。

**Why this priority**: 表格是重构中交互最重的组件，改为直接 DOM 编辑后必须完整保持操作能力。

**Independent Test**: 在含表头与多行数据的表格中执行 Tab/Shift-Tab 遍历、末列末行 Tab 新建行、撤销一次，验证导航正确且撤销恢复单格内容。

**Acceptance Scenarios**:

1. **Given** 光标在表格任一单元格，**When** 按 Tab/Shift-Tab，**Then** 焦点移到右/左侧格（末列末行 Tab 新建行）。
2. **Given** 修改某单元格内容后按一次撤销，**Then** 仅该格内容恢复。
3. **Given** 表格超过 500 行，**When** 打开该文档，**Then** 该表格退化为源码显示（可编辑源码），不强行渲染。

---

### Edge Cases

- 空文档或仅含单一标题的文档：投影与滚动行为正常，无空引用或异常。
- 选区跨越多个块：所有相交块按「进入」处理，标记显示规则一致。
- 解析未就绪（大文档后台解析中）：回退到源码形态显示，不阻塞输入。
- IME 组合输入期间：块级装饰展开冻结（既有行为，保持不回退）。
- 表格退化阈值边界（500/501 行）：行为按上述规则确定切换。
- 含未闭合围栏的文档：不崩溃、渲染按源码语义处理。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 系统 MUST 在普通正文连续键入（汉字/空格/中英标点）时不触发整视口重算，探针 typingRebuildMs 各类 P95 ≤ 8ms。
- **FR-002**: 系统 MUST 保证光标在标题、加粗、链接等标记块之间移动时正文行宽零变化（cursorWidthChange = 0）。
- **FR-003**: 块级标记（`#` `>` `-`）的显隐 MUST NOT 改变正文行的文本范围与起始位置（由左侧留白栏承载）。
- **FR-004**: 纯滚动经过已挂载的表格/公式/图片并持续 10 秒，系统 MUST 保持已挂载块零替换（scrollReplaceCount = 0）。
- **FR-005**: 大纲跳转、查找跳转、粘贴大段内容后停稳，顶部位移 MUST ≤ 1px。
- **FR-006**: 五份基准语料在即时渲染/分屏/独立预览三面的输出 MUST 一致（对比不归一化；已知差异单独登记）。
- **FR-007**: 密集语料（含表格文档）键入事务 MUST 满足 P95 ≤ 40ms、max ≤ 50ms、零 >100ms 长任务、键序正确。
- **FR-008**: 表格单元格 MUST 支持 Tab/Shift-Tab 导航、末列末行 Tab 新建行；撤销一次 MUST 恢复单格内容；超过 500 行的表格 MUST 退化为源码显示。
- **FR-009**: 既有键盘操作基线 MUST 保持不回退：正文行末 Enter 新建同级块；列表项行首 Backspace 摘标记提升为段落；空列表项 Enter/Backspace 结束列表；有序列表 Enter 编号递增；任务列表 Enter 新建 `- [ ]`；围栏内 Enter 不触发 Markdown 结构、末行 Mod-Enter 跳出；标题行 Enter 新建同层段落；Shift-Enter 插入硬换行。
- **FR-010**: 重构完成后即时渲染子系统生产代码规模 MUST ≤ 3,000 行（基线 4,665 行；统计口径见 Assumptions）。
- **FR-011**: 既有测试套件与相关原生性能门禁 MUST 全程保持通过（各阶段回归不亮红灯）。

### Non-Goals（本次不做）

- 不引入 contenteditable 块编辑器方案替换现有编辑模型。
- 不更换编辑器组件库，不删除源码模式。
- 不改变文件格式支持范围（CSV/图片/Office/PDF 等不受影响）。
- 不改动阅读面与文档会话的既有架构（已稳定）。
- 不在表格交互所需之外重构已通过验收的键盘行为。

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 打字跟手——typingRebuildMs（汉字/空格/句号）P95 ≤ 8ms；密集语料事务 P95 ≤ 40ms、max ≤ 50ms、零 >100ms 长任务（AC-36 硬线）。
- **SC-002**: 行宽稳定——cursorWidthChange = 0。
- **SC-003**: 滚动稳定——scrollReplaceCount = 0（10 秒连续滚动）；停稳顶部位移 ≤ 1px。
- **SC-004**: 三面一致——五份基准语料截图对比一致，不归一化。
- **SC-005**: 表格操作正确——Tab/Shift-Tab/新建行/单格撤销全部通过。
- **SC-006**: 可维护性——即时渲染子系统生产代码 ≤ 3,000 行（基线 4,665，净减约 1/3 以上）。
- **SC-007**: 回归零损伤——141 个既有测试文件与相关原生门禁全绿。

## Assumptions

- 行为与性能基准在改动代码前先行固定（第一阶段建立基准），基准记录存放于本地 `docs/tmp/ir-rewrite-baselines/`（已 gitignore，不入公开仓库）——所有者 2026-11-19 确认。
- 行数统计口径（FR-010/SC-006）：即时渲染子系统现行文件集为 `live-*` / `writing` / `table*` / `layout` / `spacing` 分类下的生产代码（不含测试文件）——所有者 2026-11-19 确认。
- 实施沿用已定夺的统一投影器技术方案（所有者 2026-11-19 决策），分七阶段推进、每阶段独立可撤回、前序阶段测试持续通过。
- 性能门禁在 Windows 60Hz 物理控制台环境执行；各阶段使用独立的门禁运行目录，不跨阶段复用。
- 本规格为 WHAT 层；文件级删除清单、目标文件结构、阶段细步任务在 Plan 阶段展开。
