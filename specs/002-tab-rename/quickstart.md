# Quickstart: 标签右键重命名

验证指南。实现完成后按下列场景核对，不在这里写实现。

## 准备

1. 用 `npm run tauri dev` 启动桌面应用。不要用 `cargo build --release` 直接跑桌面程序。
2. 准备一个可写目录，放入 `note.txt`（写入一行容易辨认的文字）、`same.txt`、一个无扩展名文件 `notes`，以及子文件 `notes\child.txt`。
3. 在应用中打开 `note.txt`、`notes` 和 `notes\child.txt`。

## 主路径

1. 右键 `note.txt` 标签，确认菜单有「重命名…」，同时仍有关闭和复制路径。
2. 选择重命名，确认输入框预填 `note.txt`。取消。文件名与标签不变。
3. 再次重命名为 `renamed.txt`。标签不关闭，显示 `renamed.txt`；目录里旧名消失、新名存在；原文仍在。
4. 不保存地再输入几个字，重命名为 `renamed-dirty.txt`。新输入仍在，标签仍标未保存。
5. 看窗口标题、状态栏和文件树，都是新路径。

## 拒绝与失败

1. 把文件重命名为已存在的 `same.txt`。提示同名已存在，两边文件都不变。
2. 输入 `a/b.txt` 或 `a\b.txt`。不改名。
3. 输入原名或空名。不改名。
4. 在系统里删除一个已打开且有未保存修改的文件，再从标签重命名。提示文件已不在，不出现新的空文件，未保存文字仍在。

## 边界

1. 把 `notes` 重命名为 `notes-old`。`notes\child.txt` 标签仍指向原子路径，不被改掉。
2. 右键草稿、对比、尾随台标签。菜单没有重命名。
3. 打开一张图片或一个表格文件，从标签改名。标签保持打开，不必先切到文本编辑。
4. 把 `renamed.txt` 改成 `renamed.md`。标签仍是同一文件，之后按 Markdown 展示，目录里没有第二份文件。
5. 收藏并最近打开过的文件改名后，侧栏这两处显示新路径，没有旧路径残留，也没有重复项。
6. 用键盘聚焦标签，按菜单键或 Shift+F10，能打开同一个含重命名的菜单。

## 回归

- `npm test`
- `npx tsc --noEmit`
- 新增覆盖至少包括：标签菜单对真实文件提供重命名、对三类伪标签不提供；单文件迁移不改子路径；改名失败不改标签路径。
- 若改了 Rust 持久化：`cargo test --manifest-path src-tauri/Cargo.toml`，并确认最近/收藏原位替换、不制造重复。
