# Data Model: 标签右键重命名

本功能不新增用户可见的持久化字段。它改变一个真实文件的路径最后一段，并把已经记住这条旧路径的状态改到新路径。

## 文件名

| 字段 | 规则 |
|---|---|
| 当前名称 | 路径最后一段，含扩展名 |
| 新名称 | 用户确认的字符串，去掉首尾空白后非空 |
| 禁止 | 含 `/` 或 `\`；与当前名称完全相同则不操作 |
| 目标路径 | 原目录 + 新名称。不选目录，不保留用户输入里的目录 |
| 冲突 | 目标路径已存在则拒绝，不覆盖。仅大小写不同时交给文件系统；成功则标签显示用户确认的写法 |

## 打开的文件标签

真实本地文件标签可重命名。`draft://`、`compare://`、`tail://` 不是可重命名实体。

| 状态 | 改名成功后 |
|---|---|
| 路径 | 只替换完全等于旧路径的标签。顺序、激活、滚动、书签、路由锁保留 |
| 显示名 | 由新路径最后一段得出。同名冲突时仍可带父目录，规则不变 |
| 路由 / 语言 | 用新扩展名做快速识别。无扩展名或未知扩展名保持文本。`routeLocked` 为真时不覆盖用户选定路由 |
| 未保存修改 | 留在该标签的缓冲里，键从旧路径改为新路径 |
| 只读锁、编码、软换行、分隔符、高亮覆盖、标题缓存、滚动锚 | 键从旧路径改为新路径 |
| 大小 / 修改时间 / 磁盘只读 | 跟随该标签迁到新路径；不因为改名重新读盘 |
| 已删除标记 | 若改名成功，旧路径的已删除标记不再适用 |

子路径不是同一实体。`E:\notes` 改名为 `E:\notes-old` 时，`E:\notes\a.txt` 保持不动。

## 视图

| 条件 | 结果 |
|---|---|
| 活动视图路径就是该文件，且视图有保存队列 | 改名排进保存队列；磁盘成功后视图路径改为新路径 |
| 活动视图是预览且扩展名识别未变 | 保持挂载，只更新它持有的路径 |
| 扩展名识别改变了路由，或视图不能原位改路径 | 销毁该文件的挂载与暂存，用已迁移的缓冲按新路由重挂 |
| 标签在对话框期间被关闭 | 不复活标签；磁盘改名仍然有效 |

## 路径记录

`recent.json` 的 `items`、`favorites.json` 的 `items` 与各组 `items` 都是路径字符串列表，存储格式不变。

| 规则 | 说明 |
|---|---|
| 匹配 | 规范化后与旧路径完全相等才替换 |
| 重复 | 新路径已在同一列表中时，去掉旧路径，保留已有新路径，不新增重复项 |
| 顺序 | 原位替换，不把改名文件插到最近列表队首 |
| 失败 | 配置写失败不回滚磁盘改名，也不回滚已打开标签；下次打开仍可用新路径 |

## 状态迁移

```text
确认合法新名称
  → 磁盘 rename 成功
    → 精确迁移标签、文档会话、壳层记忆、暂存视图
    → 按新扩展名更新路由/语言（尊重路由锁）
    → 原位更新最近与收藏
    → 刷新标签、标题、状态栏、文件树、侧栏
  → 磁盘 rename 失败
    → 不迁移任何内存或配置
    → 按哨兵提示同名已存在、文件已不在，或其他失败原因
```

取消、空名称、同名、含分隔符：停在第一步之前。
